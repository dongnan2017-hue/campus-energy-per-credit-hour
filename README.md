# Campus energy cost per credit hour (Fall 2026, modeled)

A Streamlit app that estimates classroom electricity cost per credit hour from public data. Modeled estimates, not meter readings. Unofficial student project, not affiliated with or endorsed by Albion College.

Run locally: `pip install -r requirements.txt` then `streamlit run app.py`.

Every source, assumption and limit is listed on the app's **Data sources** page; the **Methodology** page shows how each number is calculated. Public data only: Albion Registrar public course search, Albion news article (14 million kWh), OpenStreetMap (ODbL), NOAA climate normals, U.S. EIA. See THIRD_PARTY_NOTICES.md.
